实现与验收说明

企业与管理端使用 React 19.3、TypeScript 7、Vite 8.3；买家与公开产品页使用 Next.js 16.3.5。Spring Boot 4.1.1 与 Java 17 目标处理业务规则，PostgreSQL 16 与 Flyway 管理数据历史，Redis 支撑安全状态与实时提示。

上传采用私有文件、隔离、扫描和授权下载。AI业务助手使用本地Ollama和Qwen3 8B，限制来源并保留人工核对。

专项研发记录包含产品管理17项、询盘工作区24项、买家产品目录17项界面检查。这些工程回归不等于已验证转化提升。真实模型在若干中英文产品场景中完成样本核对，不构成行业专家或生产SLA承诺。

代码与详细验收材料可在面试交流时按需提供；本公开站点不发布私密配置或真实业务数据。
